## Commit Attribution

GitHub's contributors graph is generated from Git commit author metadata and recognized GitHub accounts.
For work completed together with Codex, commits may include this trailer:

```text

```

This records the collaboration in Git history, even if GitHub does not link the AI collaborator as a normal GitHub account.
